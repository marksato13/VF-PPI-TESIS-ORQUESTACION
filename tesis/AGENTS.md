# Contexto compartido para agentes

Antes de analizar o modificar el dataset, las variables, el modelo, el
datasheet, el PPI o las métricas, leer:

1. `docs/agent-context/ppi-data-science-context.md`.
2. La habilidad aplicable descubierta en `.agents/skills/`.
3. Las fuentes primarias que la habilidad indique.

El contexto compartido es un índice, no una fuente numérica. Toda cifra debe
volver a verificarse en el artefacto primario. No modificar artefactos
congelados ni regenerar documentos sin autorización explícita y una versión
nueva. Mantener separadas las afirmaciones planificadas, obtenidas y validadas.

`CLAUDE.md` conserva el contexto operativo detallado del laboratorio. Este
archivo y el documento compartido alinean a Codex con Claude para las tareas de
ciencia de datos y revisión científica.
