# Revisión Claude — canario TCP 200 Mbit/s F1

Fecha: 26 de julio de 2026. Herramienta: Claude Code 2.1.217. Modelo: Haiku. Alcance: resumen técnico, sin operación ni edición.

Claude emitió **ACEPTAR** al comprobar entrega de 500,039,680 bytes en ambos extremos, ~200 Mbit/s, PCAP íntegro, cero drops de captura, recursos disponibles, hashes y admisión 20/0/125 del ensamblador.

## Límites del dictamen

- Cinco retransmisiones no se dividen entre bytes ni forman una tasa válida.
- No existe umbral formal de retransmisiones.
- Cero drops de tcpdump/Suricata evalúa el sistema de observación, no prueba cero pérdida de red.
- Bytes iguales y `error=null` prueban entrega completa en aplicación.
- Las tres filas son ventanas de un episodio.
- La alerta de clasificación iperf3 no es ground truth de ataque.

Se restringe la frase de Claude “retransmisiones normales”: la causa no fue determinada. Su aceptación se apoya en el conjunto de gates superados, no en declarar normal cualquier número de retransmisiones.

Dictamen final: **ACEPTAR CON LIMITACIONES**.
