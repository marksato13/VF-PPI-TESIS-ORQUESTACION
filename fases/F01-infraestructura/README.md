# F01 · Infraestructura reproducible

| | |
|---|---|
| **Identificador** | `PHASE-01` |
| **Estado** | Validada en el producto |

## Objetivo

Que el entorno se pueda reconstruir desde cero y se demuestre.

## Criterios de entrada

Sin esto, la fase no empieza:

- Alcance definido en F00

## Criterios de salida

La fase **no está cerrada** hasta que existan los siete elementos del criterio de
finalización —configuración persistente, prueba positiva, prueba negativa,
evidencia fechada, evaluación de riesgos, documentación reproducible y commit
identificable— **y además**:

- Diagrama de red
- Inventario de versiones
- Runbooks
- Healthchecks
- **Evidencia de restauración de backup**
